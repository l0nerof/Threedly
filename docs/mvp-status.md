## First Release Scope

The first release is a closed free beta. Free/Pro/Max remain part of the access model; Pro/Max will be assigned manually through administrative access. Permission to make these assignments has been verified by local DB tests; an example is in `docs/development-guide.md`.

Real payments, payment-provider selection, receiving funds and automatic subscription management are deferred until the final stage. They do not block the closed beta. Following designers (`designer_follows`) is a separate feature from paid subscriptions.

The main beta flow is registration → model search → details → access and quota check → file delivery → library history. The creator flow connects the editor → preview of current changes → manual draft save or publication → catalog listing. Local Playwright has verified the end-to-end creator flow, actual downloaded bytes, repeat downloads without additional quota, registration with email/OTP and password recovery. External email, broader network failures and remaining negative scenarios have separate gaps documented in `e2e/README.md`.
